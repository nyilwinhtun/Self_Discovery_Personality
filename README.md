# Self Discovery

မြန်မာဘာသာဖြင့် ကိုယ့်ပင်ကိုစရိုက်နှင့် အတွင်းစိတ်ကို လေ့လာနိုင်ရန် တည်ဆောက်ထားသော React + Vite Web App ဖြစ်သည်။

> **လက်ရှိအခြေအနေ — BETA စမ်းသပ်ဗားရှင်း**
>
> ဤ App ကို အသုံးပြုသူများထံမှ အကြံပြုချက်ရယူပြီး တိုးတက်အောင် ပြင်ဆင်နေဆဲဖြစ်သည်။ မေးခွန်း၊ မြန်မာစာအသုံးအနှုန်း၊ ရလဒ်ရှင်းလင်းချက်နှင့် လုပ်ဆောင်ချက်အချို့ ပြောင်းလဲနိုင်ပြီး မမျှော်လင့်ထားသော အမှားများလည်း ဖြစ်နိုင်သည်။ ထုတ်လုပ်ပြီး တည်ငြိမ်သော Version အဖြစ် မသတ်မှတ်ရသေးပါ။

### Beta စမ်းသပ်သူများ သတိပြုရန်

- ရလဒ်များသည် မိမိကိုယ်ကို ပြန်လည်သုံးသပ်ရန် အထောက်အကူပေးသည့် အညွှန်းများသာဖြစ်ပြီး ရောဂါရှာဖွေခြင်း၊ ကုသမှု သို့မဟုတ် ဆေးဘက်ဆိုင်ရာ အကြံဉာဏ် မဟုတ်ပါ။ Career Interest ရလဒ်သည် အလုပ်ရရှိမှု သို့မဟုတ် အောင်မြင်မှုကို အာမမခံပါ။
- TraitLens နှင့် InnerCompass မေးခွန်းများ၏ လက်ရှိမူများကို ယုံကြည်စိတ်ချရမှုနှင့် တိုင်းတာမှုတိကျမှု စံနှုန်းများဖြင့် အပြည့်အဝ အတည်ပြုထားခြင်း မရှိသေးပါ။ InnerCompass သည် Pilot Reflection ဖြစ်သည်။
- အဖြေများ၊ Draft နှင့် History များကို လက်ရှိ Browser/စက်၏ LocalStorage ထဲတွင်သာ သိမ်းဆည်းပြီး Cloud Sync မပါဝင်သေးပါ။ Private/Incognito mode သုံးခြင်း၊ Browser Data ရှင်းခြင်း သို့မဟုတ် Browser/စက်ပြောင်းခြင်းကြောင့် Data ပျောက်နိုင်သည်။
- Browser Data ရှင်းမီ JSON Backup ထုတ်ယူပါ။ Backup ဖိုင်တွင် ကိုယ်ရေးကိုယ်တာ အဖြေများနှင့် ရလဒ်များ ပါဝင်နိုင်သဖြင့် လုံခြုံစွာ သိမ်းဆည်းပါ။
- မဖြေလိုသော မေးခွန်းရှိပါက စမ်းသပ်မှုကို ရပ်နားနိုင်သည်။ မိမိအဖြေများကို အခြားသူများနှင့် မျှဝေရန် မလိုအပ်ပါ။
- Error တွေ့ပါက အသုံးပြုသည့် စက်၊ Browser အမျိုးအစား၊ ဖြစ်ပွားပုံနှင့် Screenshot (ကိုယ်ရေးအချက်အလက်များကို ဖုံးကွယ်ပြီး) ဖြင့် အကြံပြုချက်ပေးနိုင်သည်။

## လက်ရှိပါဝင်သည့်အပိုင်းများ

- **Knowledge Center (Beta Draft)** — စိတ်ပညာဆိုင်ရာ စကားလုံး ၃၀ ကို အုပ်စု ၆ ခုဖြင့် ရှာဖွေဖတ်ရှုနိုင်သည်။ TraitLens နှင့် InnerCompass မေးခွန်းအချို့တွင် ဆက်စပ်စကားလုံးအတွက် `ⓘ` ရှင်းလင်းချက်ကို တိုက်ရိုက်ဖွင့်နိုင်သည်။ အကြောင်းအရာအားလုံးသည် မူကြမ်းဖြစ်ပြီး ဘာသာစကားနှင့် စိတ်ပညာကျွမ်းကျင်သူ စစ်ဆေးမှု မပြီးသေးပါ။

- **TraitLens** — ပင်ကိုစရိုက်ကို လေ့လာခြင်း။ မေးခွန်း ၃၀ / ၆၀ / ၁၂၀။
- **InnerCompass** — စိတ်နေသဘောထားကို လေ့လာခြင်း။ မေးခွန်း ၃၀ ပါ Pilot Reflection ဖြစ်ပြီး စိတ်ပညာဆိုင်ရာ အတည်ပြုစမ်းသပ်မှု မဟုတ်သေးပါ။
- **Career Interest** — စိတ်ဝင်စားသည့် လုပ်ဆောင်မှုအမျိုးအစားများကို လေ့လာသည့် သီးခြား Module။
- **JSON Backup / Restore** — LocalStorage ထဲရှိ Draft နှင့် History များကို Backup ပြုလုပ်ပြီး ပြန်ထည့်နိုင်သည်။

BondSense, ValueMap နှင့် Skills Assessment တို့သည် အနာဂတ်တွင် တည်ဆောက်ရန် စီစဉ်ထားသော အပိုင်းများဖြစ်သည်။

## GitHub Pages ဖြင့် ထုတ်ဝေခြင်း

ဤ React + Vite Project ကို GitHub Pages တွင် ထုတ်ဝေရာ၌ Source Code ကို တိုက်ရိုက် Publish မလုပ်ဘဲ Vite Build ထွက်လာသော `dist/` ကိုသာ Deploy လုပ်ရပါမည်။ `.github/workflows/deploy.yml` ကို ထည့်သွင်းထားပြီး `main` branch သို့ Push လုပ်သည့်အခါ Validate → Build → Deploy အလိုအလျောက် လုပ်ဆောင်မည်ဖြစ်သည်။ GitHub Repository ရှိ **Settings → Pages → Build and deployment → Source** ကို **GitHub Actions** ဟု သတ်မှတ်ပါ။ အသေးစိတ်ကို [`GitHub Pages Deployment Guide`](./docs/01-project/GITHUB_PAGES_DEPLOY_GUIDE.md) တွင် ဖတ်ပါ။

## စတင်အသုံးပြုရန်

လိုအပ်ချက်: Node.js 20.19+ သို့မဟုတ် 22.12+ ကို အသုံးပြုရန် အကြံပြုသည်။

```bash
npm install
npm run validate:all
npm run build
npm run dev
```

## Data နှင့် ကိုယ်ရေးလုံခြုံမှု

- လက်ရှိ Assessment အဖြေများကို LocalStorage ထဲတွင် သိမ်းဆည်းသည်။
- LocalStorage သည် Browser/Device အလိုက် သီးခြားဖြစ်ပြီး Cloud Sync မပါဝင်သေးပါ။
- Browser Data ရှင်းမီ JSON Backup ထုတ်ထားပါ။
- Backup ဖိုင်တွင် ကိုယ်ရေးကိုယ်တာ အဖြေများနှင့် ရလဒ်များ ပါဝင်နိုင်သဖြင့် လုံခြုံသောနေရာတွင်သာ သိမ်းပါ။
- မူလ LocalStorage Key `self-discovery-personality-v1` ကို ထိန်းသိမ်းထားသည်။

## စိတ်ပညာဆိုင်ရာ ကန့်သတ်ချက်

TraitLens နှင့် InnerCompass ၏ လက်ရှိ မြန်မာမေးခွန်းများသည် ကိုယ်တိုင်ပြန်လည်သုံးသပ်ရန် ရေးဆွဲထားသော မူကြမ်းများဖြစ်သည်။ သက်ဆိုင်ရာ စံနှုန်း၊ ယုံကြည်စိတ်ချရမှု (reliability) နှင့် တိုင်းတာမှုတိကျမှု (validity) ကို အပြည့်အဝ အတည်ပြုထားသော စိတ်ပညာစမ်းသပ်မှုများ မဟုတ်သေးပါ။ ရောဂါရှာဖွေခြင်း၊ ဆေးဘက်ဆိုင်ရာ ဆုံးဖြတ်ချက် သို့မဟုတ် လူတစ်ဦး၏ အရည်အချင်းကို အပြီးသတ်ဆုံးဖြတ်ရန် မသုံးပါနှင့်။
