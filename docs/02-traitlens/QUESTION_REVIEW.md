# Self Discovery — မေးခွန်းအရည်အသွေး စစ်ဆေးမှတ်တမ်း

ဤစာတမ်းသည် လက်ရှိမေးခွန်း ၁၂၀ ခုကို မြန်မာဘာသာနားလည်လွယ်မှု၊ မေးခွန်းတစ်ခုလျှင် အယူအဆတစ်ခုတည်းပါဝင်မှု၊ မေးခွန်းနှင့် သက်ဆိုင်ရာအကြောင်းအရာကိုက်ညီမှု၊ ပြောင်းပြန်အမှတ်ပေးမှုတို့အပေါ် အခြေခံပြီး စစ်ဆေးရာမှ တွေ့ရှိထားသော အချက်များကို စုစည်းထားခြင်းဖြစ်သည်။

**အရေးကြီးသော ကန့်သတ်ချက်** — ဤသည် ဘာသာစကားနှင့် ဖွဲ့စည်းပုံဆိုင်ရာ အယ်ဒီတာစစ်ဆေးမှုသာဖြစ်သည်။ စိတ်ပညာကျွမ်းကျင်သူ၏ သုံးသပ်ချက်၊ အသုံးပြုသူအုပ်စုနှင့် စမ်းသပ်မှု၊ Reliability နှင့် Validity စစ်ဆေးမှုတို့ကို အစားမထိုးနိုင်ပါ။

## လက်ရှိ Assessment ဖွဲ့စည်းပုံ

| အဆင့် | မေးခွန်း | ရလဒ်မှာ ဖော်ပြမည့်အရာ |
|---|---:|---|
| အခြေခံ | ၃၀ | Big Five အဓိကကဏ္ဍ ၅ ခု၏ အညွှန်းရမှတ် |
| အသေးစိတ် | ၆၀ | Big Five အဓိကကဏ္ဍ ၅ ခု၏ ပိုမိုတည်ငြိမ်သော အညွှန်းရမှတ် |
| နက်ရှိုင်း | ၁၂၀ | အဓိကကဏ္ဍ ၅ ခုနှင့် စမ်းသပ်လေ့လာရေး ကဏ္ဍခွဲ ၃၀ ၏ အညွှန်းရမှတ် |

၃၀ နှင့် ၆၀ မေးခွန်းအဆင့်များတွင် ကဏ္ဍခွဲ ၃၀ ရမှတ်ကို မဖော်ပြပါ။ ကဏ္ဍခွဲ ၃၀ ကို ၁၂၀ မေးခွန်းအဆင့်တွင်သာ မေးခွန်း ၄ ခုစီဖြင့် စမ်းသပ်အညွှန်းအဖြစ် တွက်ချက်သည်။ ကဏ္ဍခွဲများသည် ဤ Project အတွက် ဖန်တီးထားသော စူးစမ်းလေ့လာရေး အုပ်စုများဖြစ်ပြီး စံသတ်မှတ်ထားသော Facet Scale များမဟုတ်ပါ။

## မေးခွန်းစစ်ဆေးရာတွင် အသုံးပြုသည့် စံနှုန်းများ

1. **အယူအဆတစ်ခုတည်း** — မေးခွန်းတစ်ခုထဲတွင် အပြုအမူနှစ်မျိုး သို့မဟုတ် ပိုမိုများပြားစွာ မပေါင်းသင့်ပါ။
2. **နေ့စဉ်သုံးစကား** — နားလည်ရခက်သော စာပေစကား၊ ဘာသာပြန်ပုံစံကျလွန်းသော စကားလုံးများကို လျှော့သုံးရန်။
3. **အပြစ်တင်သလို မဖြစ်စေရန်** — အဖြေတစ်ခုကို လူကောင်း/လူဆိုး၊ အောင်မြင်/မအောင်မြင်ဟု မခံစားစေရန်။
4. **အခြေအနေမူတည်မှု** — အလုပ်၊ ငွေကြေး၊ ပညာရေး သို့မဟုတ် လူမှုအခွင့်အလမ်းရှိမှသာ ဖြေနိုင်သော မေးခွန်းများကို သတိထားရန်။
5. **ပြောင်းပြန်အမှတ်ပေးမှု ရှင်းလင်းရန်** — အနုတ်သဘောဝါကျများကို လွယ်ကူစွာ နားလည်နိုင်စေရန်၊ နှစ်ထပ်အငြင်းပုံစံကို ရှောင်ရန်။
6. **ကဏ္ဍနှင့် ကိုက်ညီမှု** — မေးခွန်းသည် ချိတ်ဆက်ထားသည့် Dimension/Topic Cluster ကို တကယ်တိုင်းတာနိုင်ရန်။

## ဖြေဆိုသူအတွက် လမ်းညွှန်

- ကိုယ်ဖြစ်ချင်တဲ့ပုံစံမဟုတ်ဘဲ ပုံမှန်အားဖြင့် ဘယ်လိုပြုမူတတ်သလဲကို ဖြေပါ။
- ဒီနေ့တစ်နေ့တည်းရဲ့ စိတ်အခြေအနေကိုသာ မစဉ်းစားပါနှင့်။
- အဖြေတစ်ခုကို အကောင်း/အဆိုးဟု မသတ်မှတ်ပါ။
- မသေချာပါက မေးခွန်းကို ကျော်ထားပြီး နောက်မှ ပြန်ဖြေနိုင်သည်။

## နောက်တစ်ကြိမ် မေးခွန်းစာသားပြင်ဆင်မည့်အခါ လိုက်နာရန်

1. Question Bank Version အသစ်တစ်ခု ထုတ်ပါ။
2. မပြီးသေးသော Draft များကို မေးခွန်းစာသားဟောင်းနှင့်ပဲ ပြန်ဆက်နိုင်ရန် Version အလိုက် Question Bank ကို ထိန်းသိမ်းပါ။
3. ID တစ်ခုတည်းအတွက် စာသားပြောင်းလဲပါက အဟောင်းအဖြေကို အသစ်စာသားအပေါ် အလိုအလျောက် မသုံးပါနှင့်။
4. မြန်မာဘာသာ Native Speaker များနှင့် နားလည်မှုစမ်းသပ်မှု (Cognitive Interview) လုပ်ပါ။
5. အသုံးပြုသူအုပ်စုတစ်ခုအပေါ် Pilot Test ပြုလုပ်ပြီး မေးခွန်းတစ်ခုချင်း၏ ဖြေဆိုပုံနှင့် အတွင်းညီညွတ်မှုကို စစ်ဆေးပါ။
6. လုံလောက်သော အချက်အလက်ရရှိပြီးမှသာ Reliability/Validity အကြောင်း ပြောဆိုပါ။
