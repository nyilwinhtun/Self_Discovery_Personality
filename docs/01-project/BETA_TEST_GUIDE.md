# Beta စမ်းသပ်သူများအတွက် လမ်းညွှန်

## လက်ရှိအခြေအနေ

Self Discovery သည် လက်ရှိတွင် **Beta စမ်းသပ်ဗားရှင်း** ဖြစ်သည်။ အသုံးပြုသူများ၏ အကြံပြုချက်များအပေါ် အခြေခံ၍ မေးခွန်း၊ ဘာသာစကား၊ ရလဒ်ရှင်းလင်းချက်၊ ဒီဇိုင်းနှင့် လုပ်ဆောင်ချက်များကို ပြင်ဆင်နိုင်သည်။ မမျှော်လင့်ထားသော Error များလည်း ဖြစ်နိုင်သည်။

## စမ်းသပ်သူများ သတိပြုရန်

1. **ရလဒ်ကို အညွှန်းအဖြစ်သာ အသုံးပြုပါ။** ရလဒ်သည် ကိုယ့်ကိုယ်ကို ပြန်လည်သုံးသပ်ရန် ကူညီပေးသည့် အချက်အလက်ဖြစ်ပြီး သင့်ကို အပြီးသတ်သတ်မှတ်ခြင်း သို့မဟုတ် အခြားသူများနှင့် အဆင့်ချင်းနှိုင်းယှဉ်ခြင်း မဟုတ်ပါ။ Career Interest ရလဒ်သည် အလုပ်ရရှိမှု သို့မဟုတ် အောင်မြင်မှုကို အာမမခံပါ။
2. **ရောဂါရှာဖွေခြင်းအတွက် မသုံးပါနှင့်။** App သည် စိတ်ကျန်းမာရေးဆိုင်ရာ Diagnosis၊ ကုသမှု၊ ဆေးဝါးသုံးစွဲမှု သို့မဟုတ် ပညာရှင်၏ အကြံဉာဏ်ကို အစားမထိုးနိုင်ပါ။
3. **မေးခွန်းများနှင့် ရလဒ်များကို အတည်ပြုထားပြီးဟု မယူဆပါနှင့်။** TraitLens နှင့် InnerCompass ၏ လက်ရှိမေးခွန်းများသည် ပြန်လည်သုံးသပ်ရန် ရေးဆွဲထားသော မူများဖြစ်ပြီး စိတ်ပညာဆိုင်ရာ ယုံကြည်စိတ်ချရမှုနှင့် တိုင်းတာမှုတိကျမှုကို အပြည့်အဝ အတည်ပြုထားခြင်း မရှိသေးပါ။ InnerCompass သည် Pilot Reflection ဖြစ်သည်။
4. **ကိုယ်ရေးကိုယ်တာအချက်အလက်ကို ကာကွယ်ပါ။** မလိုအပ်သော အမည်၊ ဖုန်းနံပါတ်၊ လိပ်စာ စသည့် အချက်အလက်များကို မထည့်ပါနှင့်။ မဖြေလိုသော မေးခွန်းရှိပါက စမ်းသပ်မှုကို ရပ်နားနိုင်သည်။
5. **Local Data ကို သတိထားပါ။** အဖြေများ၊ Draft နှင့် History များသည် လက်ရှိ Browser/စက်၏ LocalStorage ထဲတွင်သာ သိမ်းဆည်းသည်။ Cloud Sync မရှိသေးပါ။ Private/Incognito mode ဖြင့် သုံးပါက session ပြီးဆုံးချိန်တွင် Data ပျောက်နိုင်သည်။ Browser Data ရှင်းခြင်း သို့မဟုတ် စက်/Browser ပြောင်းခြင်းကြောင့်လည်း Data မရနိုင်တော့ပါ။
6. **Backup ကို လုံခြုံစွာ သိမ်းပါ။** Browser Data မရှင်းမီ JSON Backup ထုတ်ယူပါ။ Backup ဖိုင်တွင် မိမိ၏ အဖြေများနှင့် ရလဒ်များ ပါနိုင်သောကြောင့် အခြားသူများထံ မမျှဝေပါနှင့်။

## Feedback ပေးရာတွင်

Error သို့မဟုတ် နားမလည်သောအချက်တွေ့ပါက အောက်ပါအချက်များကို ပြောပြပေးပါ။

- အသုံးပြုသည့် စက်အမျိုးအစား (ဥပမာ Android ဖုန်း၊ iPhone၊ Laptop)
- Browser အမျိုးအစားနှင့် သိရှိပါက Version
- ဘယ်စာမျက်နှာ/ဘယ်အဆင့်မှာ ဖြစ်သည်
- မျှော်လင့်ထားသည့်အရာနှင့် တကယ်ဖြစ်သည့်အရာ
- Screenshot ပေးမည်ဆိုပါက အမည်၊ အဖြေ၊ ရလဒ်ကဲ့သို့ ကိုယ်ရေးကိုယ်တာအချက်အလက်များကို အရင်ဖုံးကွယ်ပါ

Feedback ပေးရန်အတွက် မိမိ၏ Assessment အဖြေများ၊ ရလဒ်များ သို့မဟုတ် JSON Backup ဖိုင်ကို ပေးရန် မလိုအပ်ပါ။
