# InnerCompass — Before You Begin V0.2.0

## မစတင်မီ သိထားသင့်သော အချက်များ

### ဒီမေးခွန်းအစုရဲ့ ရည်ရွယ်ချက်

InnerCompass သည် နေ့စဉ်ဘဝတွင် ကိုယ့်ကိုယ်ကို၊ အခြားသူများကို၊ သဘောထားမတူမှုများကိုနှင့် ကိုယ်ပိုင်လုပ်ဆောင်မှုများကို မည်သို့ကိုင်တွယ်တတ်သလဲဆိုတာ ပြန်လည်သုံးသပ်ရန် ရေးဆွဲထားသော မေးခွန်းမူကြမ်းဖြစ်သည်။ သင့်ကို အမျိုးအစားတစ်ခုတည်းဖြင့် အပြီးသတ်သတ်မှတ်ရန် မဟုတ်ပါ။

### ဘယ်လိုဖြေဆိုသင့်သလဲ။

- ကိုယ်ဖြစ်ချင်သည့်ပုံစံမဟုတ်ဘဲ ပုံမှန်နေ့စဉ်ဘဝတွင် ဖြစ်တတ်သည့်ပုံစံကို စဉ်းစားပါ။
- တစ်ကြိမ်တည်းသော ထူးခြားဖြစ်ရပ်ထက် ပုံမှန်အတွေ့အကြုံကို အခြေခံပါ။
- အဖြေမှန်၊ အဖြေမှား မရှိပါ။
- မေးခွန်းတစ်ခုကို မသက်မသာဖြစ်ပါက ကျော်ထားနိုင်သည်။ ကိုယ်ရေးအတွေ့အကြုံကို အသေးစိတ်ရှင်းပြရန် မလိုပါ။
- မေးခွန်းတိုင်းကို အလွန်အကျွံ မစဉ်းစားဘဲ ကိုယ့်အတွေ့အကြုံနှင့် အနီးစပ်ဆုံးအဖြေကို ရွေးပါ။

### အဖြေရွေးချယ်မှု

1. လုံးဝ မကိုက်ညီပါ
2. မကိုက်ညီပါ
3. အလယ်အလတ်ပါ
4. ကိုက်ညီပါသည်
5. အလွန်ကိုက်ညီပါသည်

### ဖြေဆိုမှုကို စီမံနိုင်ပုံ

- မေးခွန်းကို ကျော်ပြီး နောက်မှ ပြန်ဖြေနိုင်သည်။
- ယခင်မေးခွန်းကို ပြန်သွားပြီး အဖြေပြင်နိုင်သည်။
- အချိန်မရွေး ခဏရပ်ကာ နောက်မှ ဆက်ဖြေနိုင်သည်။
- အဖြေများကို လက်ရှိ Browser နှင့် စက်ထဲတွင် သိမ်းဆည်းမည်။
- Browser Data ရှင်းမိပါက အချက်အလက်ပျောက်နိုင်သဖြင့် JSON Backup ကို လုံခြုံစွာ သိမ်းထားပါ။

### ရလဒ်ကို ဘယ်လိုနားလည်ရမလဲ။

ရလဒ်သည် ကိုယ်ဖြေထားသောအဖြေများကို အခြေခံသည့် မူကြမ်းအဆင့် ကိုယ်တိုင်ပြန်လည်သုံးသပ်မှု အညွှန်းသာဖြစ်သည်။ အမှတ်မြင့်ခြင်း၊ နိမ့်ခြင်းသည် ကောင်းသူ၊ မကောင်းသူ သတ်မှတ်ချက် မဟုတ်ပါ။ အခြားသူများနှင့် နှိုင်းယှဉ်ထားသည့် အဆင့်လည်း မဟုတ်ပါ။ အခြေအနေ၊ ပတ်ဝန်းကျင်နှင့် အတွေ့အကြုံအလိုက် ကိုယ့်အပြုအမူလည်း ကွဲပြားနိုင်သည်။

### ဘာကို မဆုံးဖြတ်ပေးသလဲ။

ဤမေးခွန်းအစုသည် စိတ်ကျန်းမာရေးရောဂါ၊ ဉာဏ်ရည်၊ ကိုယ်ကျင့်တရားတန်ဖိုး၊ Trauma၊ အနာဂတ်အပြုအမူ သို့မဟုတ် အလုပ်အကိုင်သင့်တော်မှုကို မဆုံးဖြတ်ပေးပါ။ ဆေးဘက်ဆိုင်ရာ သို့မဟုတ် စိတ်ကျန်းမာရေး Diagnosis အတွက် မသုံးပါနှင့်။

### ကိုယ်ရေးအချက်အလက်

လက်ရှိစမ်းသပ်မူတွင် အဖြေများကို LocalStorage မှတစ်ဆင့် Browser ထဲ၌သာ သိမ်းဆည်းရန် ရည်ရွယ်ထားသည်။ Cloud သို့ အလိုအလျောက် ပို့ခြင်း မရှိပါ။ Backup ဖိုင်ထဲတွင် ကိုယ်ရေးကိုယ်တာအဖြေများ ပါဝင်နိုင်သဖြင့် လုံခြုံသောနေရာတွင်သာ သိမ်းပါ။
