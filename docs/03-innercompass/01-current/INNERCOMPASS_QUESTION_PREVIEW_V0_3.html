စိတ်နေသဘောထားကို လေ့လာခြင်း

မြန်မာစကားလုံး ပိုရိုးရှင်းအောင် ပြင်ဆင်ထားသော မေးခွန်းမူကြမ်း V0.3.0

အတွင်းပိုင်းသုံးသပ်ရန်သာ · Active Test မဟုတ်သေး
ဘယ်လိုဖတ်ကြည့်ရမလဲ။
မေးခွန်းတစ်ခုချင်းစီကို ဖတ်ပြီး ကိုယ်နားလည်လိုက်တဲ့ အဓိပ္ပာယ်ကို စဉ်းစားပါ။ မရှင်းလင်းတဲ့ စကားလုံး၊ အဓိပ္ပာယ်ထပ်နေတယ်လို့ ခံစားရတဲ့ မေးခွန်း၊ အဖြေရွေးရခက်စေတဲ့ မေးခွန်းတွေကို မှတ်သားပါ။ ဒီမူကြမ်းကို စိတ်ပညာဆိုင်ရာ အတည်ပြုထားတဲ့ Test အဖြစ် မသုံးသင့်သေးပါ။
IC1

ရိုးသားစွာ ပြောဆိုမှုနှင့် တာဝန်ယူမှု

ကတိအကြောင်း ပွင့်လင်းစွာ ပြောဆိုပုံ၊ ကိုယ့်လုပ်ရပ်အတွက် တာဝန်ယူပုံနှင့် အခြားသူများ၏ ပါဝင်မှုကို အသိအမှတ်ပြုပုံကို ပြန်လည်သုံးသပ်ရန်။

မေးခွန်း ၅ ခု
  1. 01ကတိမတည်နိုင်တော့ရင် သက်ဆိုင်သူကို ကြိုပြောတတ်တယ်။
  2. 02ကိုယ့်ဆုံးဖြတ်ချက်ကြောင့် တခြားသူတွေ ထိခိုက်နိုင်မလား စဉ်းစားတတ်တယ်။
  3. 03ကိုယ်မှားခဲ့ရင် ဝန်ခံတတ်တယ်။
  4. 04ကိုယ့်အကျိုးရှိအောင် ပြောတဲ့အခါ ကိုယ့်ဘက်က မကောင်းတဲ့အချက်ကို ချန်ထားတတ်တယ်။ပြောင်းပြန်အမှတ်
  5. 05အဖွဲ့လိုက် အောင်မြင်ရင် ကူညီပေးခဲ့သူတွေကို ကျေးဇူးတင်ကြောင်း ပြောတတ်တယ်။
IC2

စိတ်ခံစားချက်ကို သိရှိကိုင်တွယ်ပုံ

ကိုယ့်ခံစားချက်ကို သတိထားမိပုံ၊ စိတ်ဖိစီးချိန် ကိုယ့်ကိုယ်ကို ကူညီပုံ၊ အကူအညီတောင်းပုံနှင့် စိတ်အနှောင့်အယှက်ပြီးနောက် အာရုံပြန်စိုက်ပုံကို ပြန်လည်သုံးသပ်ရန်။

မေးခွန်း ၅ ခု
  1. 06ကိုယ် ဘယ်လိုခံစားနေရတယ်ဆိုတာ သတိထားမိတတ်တယ်။
  2. 07စိတ်ဖိစီးလာရင် ခဏနားပြီး စိတ်အေးအောင် ကြိုးစားတတ်တယ်။
  3. 08တစ်ယောက်တည်း မဖြေရှင်းနိုင်တဲ့အခါ အကူအညီတောင်းတတ်တယ်။
  4. 09တခြားသူ စိတ်မကောင်းဖြစ်နေတဲ့အခါ သတိထားမိတတ်တယ်။
  5. 10စိတ်မကောင်းဖြစ်ပြီးနောက် လုပ်စရာတွေကို ပြန်အာရုံစိုက်ဖို့ ခက်တတ်တယ်။ပြောင်းပြန်အမှတ်
IC3

လူမှုအခြေအနေတွင် ကိုယ့်ကိုယ်ကို ဖော်ပြပုံ

မရင်းနှီးသူများနှင့် စကားစတင်ပုံ၊ အုပ်စုအတွင်း ကိုယ့်အမြင်ပြောပုံနှင့် လူမှုအခြေအနေများတွင် ပါဝင်ပုံကို ပြန်လည်သုံးသပ်ရန်။

မေးခွန်း ၅ ခု
  1. 11မရင်းနှီးသေးတဲ့သူနဲ့ စကားစပြောဖို့ လွယ်တယ်။
  2. 12အုပ်စုထဲမှာ ကိုယ့်အမြင်ကို ပြောပြတတ်တယ်။
  3. 13လူအများနဲ့ အချိန်ဖြုန်းရတာကို နှစ်သက်တယ်။
  4. 14လူအများရှေ့မှာ စကားပြောရမယ်ဆိုရင် ရှောင်ချင်တတ်တယ်။ပြောင်းပြန်အမှတ်
  5. 15လူသစ်တွေနဲ့ တွေ့တဲ့အခါ ကိုယ့်အကြောင်းကို ပြောပြတတ်တယ်။
IC4

အမြင်မတူမှုကို ကိုင်တွယ်ပုံ

အမြင်မတူသူကို နားထောင်ပုံ၊ အချက်အလက်အသစ်အပေါ် ကိုယ့်အမြင်ပြင်ပုံနှင့် သဘောမတူသည့်အခါ ပြောဆိုပုံကို ပြန်လည်သုံးသပ်ရန်။

မေးခွန်း ၅ ခု
  1. 16ကိုယ်နဲ့ အမြင်မတူသူ ပြောတာကို အရင်နားထောင်ပြီးမှ ပြန်ပြောတတ်တယ်။
  2. 17အချက်အလက်အသစ်ကြောင့် ကိုယ့်အမြင်မှားနေတယ်လို့ သိရင် ပြင်တတ်တယ်။
  3. 18သဘောမတူတဲ့အခါ နှစ်ဖက်လုံးအတွက် အဆင်ပြေမယ့်နည်းလမ်း ရှာတတ်တယ်။
  4. 19ကိုယ့်အမြင်နဲ့ မတူရင် သေချာမစဉ်းစားဘဲ ငြင်းတတ်တယ်။ပြောင်းပြန်အမှတ်
  5. 20အမြင်မတူတဲ့အခါ လူကိုအပြစ်မတင်ဘဲ ပြဿနာကိုပဲ ပြောတတ်တယ်။
IC5

ကိုယ်ပိုင်စီမံမှုနှင့် ဇွဲရှိမှု

အလုပ်စီစဉ်ပုံ၊ စတင်ထားသည့်အလုပ်ကို ဆက်လုပ်ပုံ၊ အရေးကြီးသောအချက်များကို စစ်ဆေးပုံနှင့် ကိုယ်ပိုင်ပစ္စည်းများကို စနစ်တကျထားပုံကို ပြန်လည်သုံးသပ်ရန်။

မေးခွန်း ၅ ခု
  1. 21အလုပ်မစခင် ဘာကိုအရင်လုပ်မလဲ စီစဉ်တတ်တယ်။
  2. 22စလုပ်ထားတဲ့အလုပ်ကို အဆုံးထိလုပ်ဖို့ ကြိုးစားတတ်တယ်။
  3. 23အလုပ်ပြီးရင် အရေးကြီးတဲ့အချက်တွေ မှန်မမှန် ပြန်စစ်တတ်တယ်။
  4. 24သတ်မှတ်ထားတဲ့အချိန်အတွင်း အလုပ်ပြီးအောင် ကြိုးစားတတ်တယ်။
  5. 25သုံးပြီးတဲ့ပစ္စည်းတွေကို နေရာတကျ ပြန်မထားမိတတ်ဘူး။ပြောင်းပြန်အမှတ်
IC6

စူးစမ်းလိုစိတ်နှင့် အတွေးသစ်များ

မသိသေးသောအကြောင်းအရာကို လေ့လာလိုမှု၊ နည်းလမ်းအမျိုးမျိုး စဉ်းစားမှု၊ အနုပညာကို ခံစားမှုနှင့် အကြံသစ်များကို စမ်းကြည့်လိုမှုကို ပြန်လည်သုံးသပ်ရန်။

မေးခွန်း ၅ ခု
  1. 26မသိသေးတဲ့အကြောင်းအရာကို ပိုသိဖို့ ကိုယ်တိုင်ရှာဖွေတတ်တယ်။
  2. 27ပြဿနာတစ်ခုအတွက် ဖြေရှင်းနည်း အမျိုးမျိုး စဉ်းစားတတ်တယ်။
  3. 28အနုပညာလက်ရာတွေကို ကြည့်ရှုခံစားရတာ ကြိုက်တယ်။
  4. 29ကိုယ်မကြားဖူးတဲ့ အယူအဆကို သေချာမသိခင် ငြင်းပယ်တတ်တယ်။ပြောင်းပြန်အမှတ်
  5. 30နေ့စဉ်လုပ်နေကျအရာတွေကို နည်းလမ်းသစ်နဲ့ စမ်းလုပ်ကြည့်ရတာ စိတ်ဝင်စားတယ်။

အရေးကြီးသောကန့်သတ်ချက် — ဒီမေးခွန်းများသည် ကိုယ်တိုင်ပြန်လည်သုံးသပ်ရန် ဖန်တီးထားသော မူကြမ်းဖြစ်သည်။ Reliability၊ Validity၊ Norms သို့မဟုတ် Clinical Diagnostic Status ကို အတည်ပြုထားခြင်း မရှိပါ။ မေးခွန်းများသည် အဟောင်း V0.2 မူကြမ်းနှင့် သီးခြားဖြစ်သည်။
