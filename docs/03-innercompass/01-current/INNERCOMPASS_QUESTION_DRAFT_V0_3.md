# InnerCompass — မေးခွန်းမူကြမ်း V0.3.0

> **အတွင်းပိုင်းပြန်လည်သုံးသပ်ရန် မူကြမ်းသာဖြစ်သည်။** App ထဲရှိ လက်ရှိ Pilot V0.2 ကို အစားမထိုးသေးပါ။ စိတ်ပညာဆိုင်ရာ Reliability၊ Validity သို့မဟုတ် Norm များကို အတည်ပြုထားခြင်း မဟုတ်ပါ။

## 1. V0.3 ရည်ရွယ်ချက်

V0.3 တွင် မေးခွန်းစာသားများကို ပိုတို၍ နေ့စဉ်သုံး မြန်မာစကားဖြင့် ပြန်ရေးထားသည်။ မေးခွန်းတစ်ခုစီတွင် အဓိကအပြုအမူတစ်ခုသာ ပါဝင်စေရန် ကြိုးစားထားပြီး ယခင်မူကြမ်းတွင် အဓိပ္ပာယ်နီးစပ်နေသော အချို့မေးခွန်းများကို ခွဲခြားထားသည်။

ဤမူကြမ်းသည် ကိုယ်တိုင်ပြန်လည်သုံးသပ်ရန် မေးခွန်းအစုဖြစ်သည်။ HEXACO၊ Big Five သို့မဟုတ် အခြားစံချိန်စံညွှန်းမီ စစ်ဆေးမှုတစ်ခု၏ တရားဝင်ဘာသာပြန်၊ အစားထိုးပုံစံ သို့မဟုတ် တူညီသော Test မဟုတ်ပါ။

## 2. ဖြေဆိုရန် လမ်းညွှန်

- အတိတ်က ထူးခြားဖြစ်ရပ်တစ်ခုတည်းကို မစဉ်းစားဘဲ လတ်တလော လများအတွင်း ပုံမှန်ပြုမူတတ်သည့်ပုံစံကို အခြေခံပါ။
- ကိုယ်ဖြစ်ချင်သည့်ပုံစံမဟုတ်ဘဲ ကိုယ့်အကြောင်း အမှန်ထင်မြင်သည့်အတိုင်း ဖြေပါ။
- အဖြေမှန်၊ အဖြေမှား မရှိပါ။
- မသက်မသာဖြစ်သော မေးခွန်းကို ကျော်နိုင်သည်။ ကိုယ်ရေးအတွေ့အကြုံကို အသေးစိတ်ရေးရန် မလိုပါ။
- စိတ်အခြေအနေ၊ ပတ်ဝန်းကျင်၊ အခွင့်အရေးနှင့် အတွေ့အကြုံတို့ကြောင့် အဖြေကွဲပြားနိုင်သည်။

## 3. အဖြေရွေးချယ်မှု

1. လုံးဝ မကိုက်ညီပါ
2. မကိုက်ညီပါ

4. ကိုက်ညီပါသည်
5. အလွန်ကိုက်ညီပါသည်

## 4. မေးခွန်း ၃၀ ခု

### IC1 — ရိုးသားစွာ ပြောဆိုမှုနှင့် တာဝန်ယူမှု

1. ကတိမတည်နိုင်တော့ရင် သက်ဆိုင်သူကို ကြိုပြောတတ်တယ်။
2. ကိုယ့်ဆုံးဖြတ်ချက်ကြောင့် တခြားသူတွေ ထိခိုက်နိုင်မလား စဉ်းစားတတ်တယ်။
3. ကိုယ်မှားခဲ့ရင် ဝန်ခံတတ်တယ်။
4. ကိုယ့်အကျိုးရှိအောင် ပြောတဲ့အခါ ကိုယ့်ဘက်က မကောင်းတဲ့အချက်ကို ချန်ထားတတ်တယ်။ *(ပြောင်းပြန်တွက်ချက်ရန်)*
5. အဖွဲ့လိုက် အောင်မြင်ရင် ကူညီပေးခဲ့သူတွေကို ကျေးဇူးတင်ကြောင်း ပြောတတ်တယ်။

### IC2 — စိတ်ခံစားချက်ကို သိရှိကိုင်တွယ်ပုံ

6. ကိုယ် ဘယ်လိုခံစားနေရတယ်ဆိုတာ သတိထားမိတတ်တယ်။
7. စိတ်ဖိစီးလာရင် ခဏနားပြီး စိတ်အေးအောင် ကြိုးစားတတ်တယ်။
8. တစ်ယောက်တည်း မဖြေရှင်းနိုင်တဲ့အခါ အကူအညီတောင်းတတ်တယ်။
9. တခြားသူ စိတ်မကောင်းဖြစ်နေတဲ့အခါ သတိထားမိတတ်တယ်။
10. စိတ်မကောင်းဖြစ်ပြီးနောက် လုပ်စရာတွေကို ပြန်အာရုံစိုက်ဖို့ ခက်တတ်တယ်။ *(ပြောင်းပြန်တွက်ချက်ရန်)*

### IC3 — လူမှုအခြေအနေတွင် ကိုယ့်ကိုယ်ကို ဖော်ပြပုံ

11. မရင်းနှီးသေးတဲ့သူနဲ့ စကားစပြောဖို့ လွယ်တယ်။
12. အုပ်စုထဲမှာ ကိုယ့်အမြင်ကို ပြောပြတတ်တယ်။
13. လူအများနဲ့ အချိန်ဖြုန်းရတာကို နှစ်သက်တယ်။
14. လူအများရှေ့မှာ စကားပြောရမယ်ဆိုရင် ရှောင်ချင်တတ်တယ်။ *(ပြောင်းပြန်တွက်ချက်ရန်)*
15. လူသစ်တွေနဲ့ တွေ့တဲ့အခါ ကိုယ့်အကြောင်းကို ပြောပြတတ်တယ်။

### IC4 — အမြင်မတူမှုကို ကိုင်တွယ်ပုံ

16. ကိုယ်နဲ့ အမြင်မတူသူ ပြောတာကို အရင်နားထောင်ပြီးမှ ပြန်ပြောတတ်တယ်။
17. အချက်အလက်အသစ်ကြောင့် ကိုယ့်အမြင်မှားနေတယ်လို့ သိရင် ပြင်တတ်တယ်။
18. သဘောမတူတဲ့အခါ နှစ်ဖက်လုံးအတွက် အဆင်ပြေမယ့်နည်းလမ်း ရှာတတ်တယ်။
19. ကိုယ့်အမြင်နဲ့ မတူရင် သေချာမစဉ်းစားဘဲ ငြင်းတတ်တယ်။ *(ပြောင်းပြန်တွက်ချက်ရန်)*
20. အမြင်မတူတဲ့အခါ လူကိုအပြစ်မတင်ဘဲ ပြဿနာကိုပဲ ပြောတတ်တယ်။

### IC5 — ကိုယ်ပိုင်စီမံမှုနှင့် ဇွဲရှိမှု

21. အလုပ်မစခင် ဘာကိုအရင်လုပ်မလဲ စီစဉ်တတ်တယ်။
22. စလုပ်ထားတဲ့အလုပ်ကို အဆုံးထိလုပ်ဖို့ ကြိုးစားတတ်တယ်။
23. အလုပ်ပြီးရင် အရေးကြီးတဲ့အချက်တွေ မှန်မမှန် ပြန်စစ်တတ်တယ်။
24. သတ်မှတ်ထားတဲ့အချိန်အတွင်း အလုပ်ပြီးအောင် ကြိုးစားတတ်တယ်။
25. သုံးပြီးတဲ့ပစ္စည်းတွေကို နေရာတကျ ပြန်မထားမိတတ်ဘူး။ *(ပြောင်းပြန်တွက်ချက်ရန်)*

### IC6 — စူးစမ်းလိုစိတ်နှင့် အတွေးသစ်များ

26. မသိသေးတဲ့အကြောင်းအရာကို ပိုသိဖို့ ကိုယ်တိုင်ရှာဖွေတတ်တယ်။
27. ပြဿနာတစ်ခုအတွက် ဖြေရှင်းနည်း အမျိုးမျိုး စဉ်းစားတတ်တယ်။
28. အနုပညာလက်ရာတွေကို ကြည့်ရှုခံစားရတာ ကြိုက်တယ်။
29. ကိုယ်မကြားဖူးတဲ့ အယူအဆကို သေချာမသိခင် ငြင်းပယ်တတ်တယ်။ *(ပြောင်းပြန်တွက်ချက်ရန်)*
30. နေ့စဉ်လုပ်နေကျအရာတွေကို နည်းလမ်းသစ်နဲ့ စမ်းလုပ်ကြည့်ရတာ စိတ်ဝင်စားတယ်။

## 6. အရေးကြီးသော ကန့်သတ်ချက်

- ရလဒ်သည် မိမိကိုယ်ကို ပြန်လည်သုံးသပ်ရန် အညွှန်းသာဖြစ်သည်။
- ရမှတ်ကို လူဦးရေစံနှုန်း၊ Percentile သို့မဟုတ် ရောဂါရှာဖွေမှုအဖြစ် မဖော်ပြရ။
- ရမှတ်နည်းခြင်းသည် အားနည်းသူ သို့မဟုတ် လူမကောင်းဟု မဆိုလိုပါ။
- မေးခွန်းများကို စာသားအရ စစ်ဆေးထားခြင်းသည် Psychometric Validation မဟုတ်ပါ။
- Active Test အဖြစ် မဖွင့်မီ မြန်မာဘာသာတည်းဖြတ်သူ၊ စိတ်ပညာကျွမ်းကျင်သူတို့၏ သုံးသပ်မှုနှင့် Cognitive Interview လိုအပ်သည်။
