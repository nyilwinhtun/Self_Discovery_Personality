# InnerCompass — Editorial Review V0.3.0

## Review scope

ဤစာတမ်းသည် မြန်မာဘာသာဖြင့် ဖတ်ရလွယ်မှု၊ မေးခွန်းတစ်ခုတွင် အဓိကအယူအဆတစ်ခုသာရှိမှု၊ စကားလုံးအတိုချုံးမှုနှင့် အဓိပ္ပာယ်ထပ်နေမှုလျှော့ချရေးကို စာသားအဆင့်မှ ပြန်လည်သုံးသပ်ထားခြင်းသာဖြစ်သည်။ စိတ်ပညာကျွမ်းကျင်သူ Review၊ Cognitive Interview၊ Reliability သို့မဟုတ် Validity စမ်းသပ်ချက် မဟုတ်ပါ။

## Main edits from V0.2

- ရှုပ်ထွေးသော စကားစုများကို နေ့စဉ်သုံးစကားအဖြစ် ပြောင်းထားသည်။
- “သက်ဆိုင်သူ”, “အကြောင်းပြချက်”, “အကျိုးဆက်”, “အခြားဖြစ်နိုင်ခြေ” ကဲ့သို့ ပိုမိုလေးလံသောစကားလုံးများကို လိုအပ်သည့်နေရာတွင် ရိုးရှင်းစေထားသည်။
- IC2 ကို ကိုယ့်ခံစားချက်ကို သိခြင်းနှင့် ကိုင်တွယ်ခြင်းဘက်သို့ ပိုကျဉ်းစေပြီး IC3 ၏ လူမှုပါဝင်မှုနှင့် မရောထွေးစေရန် ပြင်ထားသည်။
- IC3 Q13 ကို အဖွဲ့အခန်းကဏ္ဍရှာခြင်းမှ လူမှုအချိန်ဖြုန်းမှုနှစ်သက်ခြင်းသို့ ပြောင်းထားသည်။
- IC4 Q20 ကို စိတ်တိုမှုကို ထိန်းချုပ်ခြင်းမှ အငြင်းပွားချိန်တွင် လူကိုမဝေဖန်ဘဲ ကိစ္စအပေါ်အာရုံစိုက်ခြင်းသို့ ပြောင်းထားသည်။
- IC5 Q22 ကို အနှောင့်အယှက်ပြီးနောက် ပြန်စတင်ခြင်းမှ အလုပ်ပြီးမြောက်အောင် ဆက်လက်ကြိုးစားခြင်းသို့ ရိုးရှင်းစေထားသည်။
- IC5 Q24 ကို နောက်ဆက်တွဲအကျိုးဆက် စဉ်းစားခြင်းမှ အချိန်လိုက်နာမှုသို့ ပြောင်းထားသည်။
- IC6 Q28 ကို အနုပညာနှင့် သဘာဝအလှအပ အမျိုးမျိုးပါဝင်နေရာမှ အနုပညာလက်ရာကို ခံစားမှုတစ်ခုတည်းသို့ ရိုးရှင်းစေထားသည်။
- IC6 Q30 ကို “အခြေအနေရှိလျှင်” ဟူသော ရှုပ်ထွေးမှုမပါဘဲ နေ့စဉ်အရာများကို နည်းလမ်းသစ်ဖြင့် စမ်းလိုမှုအဖြစ် ရေးထားသည်။

## Reverse-keyed items

`icv03-04`, `icv03-10`, `icv03-14`, `icv03-19`, `icv03-25`, `icv03-29`.

Reverse-keying သည် ဖြေဆိုသူကို ပိုမိုသေချာစေမည်ဟု အာမမခံပါ။ အဓိပ္ပာယ်လွဲနိုင်သဖြင့် Cognitive Interview အတွင်း သေချာစစ်ဆေးပါ။

## Structure checks

- အချက် ၆ ချက်။
- ကဏ္ဍတစ်ခုလျှင် မေးခွန်း ၅ ခု။
- စုစုပေါင်း မေးခွန်း ၃၀ ခု။
- မေးခွန်း ID ၃၀ ခု ထူးခြားသည်။
- ပြောင်းပြန်တွက်ချက်မည့် မေးခွန်း ၆ ခု၊ အချက်တစ်ခုစီလျှင် ၁ ခု။
- V0.3 ID များကို V0.2 နှင့် မတူစေရန် `icv03-` prefix သုံးထားသည်။

ဤစစ်ဆေးမှုများသည် ဖွဲ့စည်းပုံနှင့် စာသားကိုသာ စစ်ဆေးသည်။ Construct validity၊ factor structure၊ internal consistency သို့မဟုတ် test-retest reliability ကို မသက်သေပြပါ။

## Recommendation

V0.3 ကို လက်ရှိ App ရဲ့ Active Pilot အဖြစ် မပြောင်းသေးပါနှင့်။ အောက်ပါအစီအစဉ်အတိုင်း သွားရန် အကြံပြုသည်။

1. အနည်းဆုံး မြန်မာဘာသာတည်းဖြတ်သူတစ်ဦးထံ စာသားပြန်စစ်ခိုင်းပါ။
2. စိတ်ပညာ/Personality သုတေသနကျွမ်းကျင်သူတစ်ဦးထံ construct map နှင့် item intent ကို စစ်ဆေးခိုင်းပါ။
3. မတူညီသော အသက်အရွယ်၊ ပညာရေးနောက်ခံရှိသူများနှင့် Cognitive Interview ပြုလုပ်ပါ။
4. မေးခွန်းကို နားလည်ပုံ မတူညီသည့် item များကို ပြန်ပြင်ပါ။
