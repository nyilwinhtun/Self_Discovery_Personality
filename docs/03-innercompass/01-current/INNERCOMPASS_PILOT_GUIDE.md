# InnerCompass Pilot — အသုံးပြုသူနှင့် စမ်းသပ်သူ လမ်းညွှန်

## ဒီ Module က ဘာလဲ

InnerCompass သည် Self Discovery Project အတွက် ကိုယ်တိုင်ရေးဆွဲထားသော မြန်မာဘာသာ Self-Reflection မေးခွန်း ၃၀ ပါ Pilot ဖြစ်သည်။ အချက် ၆ ချက်ကို မေးခွန်း ၅ ခုစီဖြင့် လေ့လာသည်။ ၎င်းသည် HEXACO သို့မဟုတ် အခြားစံသတ်မှတ်ထားသော စိတ်ပညာစမ်းသပ်မှု၏ တရားဝင်ဘာသာပြန်၊ တူညီသောဗားရှင်း သို့မဟုတ် အစားထိုးစမ်းသပ်မှု မဟုတ်ပါ။

## ဖြေဆိုပုံ

1. Dashboard မှ InnerCompass ကို ဖွင့်ပါ။
2. Before You Begin လမ်းညွှန်ကို ဖတ်ပါ။
3. ကန့်သတ်ချက်များကို နားလည်ကြောင်း အမှန်ခြစ်ပြီး စတင်ပါ။
4. မေးခွန်းတစ်ခုစီအတွက် ကိုယ့်အတွေ့အကြုံနဲ့ ကိုက်ညီမှုကို ၁ မှ ၅ အတွင်း ရွေးပါ။
5. မသေချာသည့်မေးခွန်းကို ကျော်ထားနိုင်ပြီး Review စာရင်းမှ ပြန်ဖြေနိုင်သည်။
6. အဖြေရွေးချယ်တိုင်း Browser LocalStorage ထဲသို့ သိမ်းဆည်းသည်။ Home သို့ပြန်ပြီး နောက်မှ ဆက်လက်ဖြေနိုင်သည်။
7. အဖြေ ၃၀ ခုလုံး ပြည့်စုံမှသာ အညွှန်းရလဒ်ထုတ်ပေးမည်။

## အဖြေစကေး

- ၁ — လုံးဝ မကိုက်ညီပါ
- ၂ — မကိုက်ညီပါ
- ၃ — အလယ်အလတ်ပါ
- ၄ — ကိုက်ညီပါသည်
- ၅ — အလွန်ကိုက်ညီပါသည်

## ရမှတ်အဓိပ္ပာယ်

မေးခွန်းတစ်ခုစီကို ၁ မှ ၅ အတွင်း အမှတ်ပေးပြီး ပြောင်းပြန်တွက်ရမည့် မေးခွန်းများကို reverse scoring လုပ်သည်။ Dimension တစ်ခုစီ၏ ပျမ်းမျှကို 0–100 အညွှန်းအဖြစ် ပြောင်းလဲပြသသည်။ ၅ မေးခွန်းသာပါဝင်သည့်အတွက် ရလဒ်သည် အလွန်ကန့်သတ်ထားသော အညွှန်းဖြစ်သည်။ ၎င်းကို လူဦးရေ percentile၊ အခြားသူများနဲ့ နှိုင်းယှဉ်ချက်၊ ရောဂါရှာဖွေမှု၊ ကိုယ်ကျင့်တရားအကဲဖြတ်မှု သို့မဟုတ် တည်ငြိမ်သော personality label အဖြစ် မဖတ်ရှုရပါ။

## Data နှင့် လုံခြုံမှု

- အဖြေများကို လက်ရှိ Browser နှင့် Device ၏ LocalStorage ထဲတွင်သာ သိမ်းဆည်းသည်။
- Device ပြောင်းလဲခြင်း သို့မဟုတ် Browser Data ရှင်းလင်းခြင်းကြောင့် အဖြေများ ပျောက်နိုင်သည်။
- ပုံမှန် JSON Backup ထုတ်ထားပါ။
- Restore လုပ်ရာတွင် Merge mode ကို အကြံပြုသည်။

## မသုံးသင့်သော ရည်ရွယ်ချက်များ

- စိတ်ကျန်းမာရေးရောဂါ သို့မဟုတ် clinical diagnosis ပြုလုပ်ရန်။
- လူတစ်ယောက်၏ ရိုးသားမှု၊ အကျင့်စာရိတ္တ သို့မဟုတ် တန်ဖိုးကို အဆုံးအဖြတ်ပေးရန်။
- အလုပ်ခန့်ခြင်း၊ အလုပ်ထုတ်ခြင်း၊ ပညာရေးရွေးချယ်ခြင်း သို့မဟုတ် အရေးကြီးသောဆုံးဖြတ်ချက်များအတွက် တစ်ခုတည်းသော အထောက်အထားအဖြစ် အသုံးပြုရန်။
- အခြားသူများနှင့် နှိုင်းယှဉ်ရန်။

## စမ်းသပ်မှုအဆင့်

ဤ Module ကို UI Pilot အဖြစ် အသုံးပြုနိုင်သော်လည်း သုတေသနအရ အတည်ပြုထားခြင်း မရှိသေးပါ။ Public release မလုပ်မီ မြန်မာဘာသာကျွမ်းကျင်သူ၊ စိတ်ပညာကျွမ်းကျင်သူ၊ cognitive interview၊ pilot sample၊ reliability နှင့် validity စစ်ဆေးမှုများ လိုအပ်သည်။
