# InnerCompass V0.3 — Cognitive Interview Guide

ရည်ရွယ်ချက်မှာ ပါဝင်သူက မေးခွန်းကို ဘယ်လိုနားလည်သလဲ၊ ဘယ်လိုအတွေ့အကြုံကို စဉ်းစားပြီး အဖြေရွေးသလဲကို သိရန်ဖြစ်သည်။ အဖြေမှန်/မှား စစ်ခြင်း မဟုတ်ပါ။ စိတ်ပိုင်းဆိုင်ရာ အခြေအနေကို ရောဂါရှာဖွေခြင်းလည်း မဟုတ်ပါ။

## ပါဝင်သူအတွက် စတင်ရှင်းပြရန်

“ဒီမေးခွန်းတွေဟာ စမ်းသပ်မူကြမ်းပါ။ သင့်ကို အကဲဖြတ်တာမဟုတ်ပါဘူး။ မရှင်းလင်းတဲ့ စကားလုံး၊ နားမလည်တဲ့ မေးခွန်းရှိရင် ပြောပေးပါ။ မဖြေချင်တဲ့ မေးခွန်းကို ကျော်လို့ရပါတယ်။”

## မေးခွန်းတစ်ခုချင်းစီအတွက် မေးရန်

1. ဒီမေးခွန်းကို ကိုယ့်စကားနဲ့ ပြန်ရှင်းပြနိုင်မလား။
2. ဖြေတဲ့အခါ ဘယ်လိုအခြေအနေ ဒါမှမဟုတ် အဖြစ်အပျက်ကို စဉ်းစားခဲ့သလဲ။
3. ဘယ်စကားလုံးက နားလည်ရခက်သလဲ။
4. အဖြေ ၅ ခုထဲက ရွေးရတာ လွယ်သလား။ ဘာကြောင့်လဲ။
5. ဒီမေးခွန်းက ကိုယ်ပုံမှန်ပြုမူတတ်တာကို မေးတာလို့ ထင်သလား။

## မှတ်တမ်းတင်ရန်

- Item ID
- ပါဝင်သူက ပြန်ရှင်းပြသည့် အဓိပ္ပာယ်
- ရှုပ်ထွေးသည့် စကားလုံး
- ရွေးချယ်ရန် ခက်ခဲမှု
- တစ်ခုထက်ပိုသော အပြုအမူ ပါနေသလား
- လူမှု/ယဉ်ကျေးမှုအခြေအနေကြောင့် အဓိပ္ပာယ်ကွဲနိုင်သလား
- အကြံပြုထားသည့် ပြင်ဆင်ချက်

## ဦးစားပေးစစ်ဆေးရန် Item များ

အောက်ပါ Item များတွင် အခြေအနေ သို့မဟုတ် အဓိပ္ပာယ်လွဲနိုင်သည့် အန္တရာယ်ပိုရှိနိုင်သည်။

- `icv03-04`: ကိုယ့်အကျိုးအတွက် အချက်အလက်ချန်ထားမှု — လူမှုအရ လက်ခံလိုသောအဖြေကို ရွေးလိုစိတ်။
- `icv03-08`: အကူအညီတောင်းမှု — အကူအညီပေးနိုင်သူ/အရင်းအမြစ် မရှိခြင်း။
- `icv03-12`: အုပ်စုထဲ အမြင်ပြောမှု — အာဏာကွာဟမှု/လုံခြုံမှု/အခွင့်အရေး။
- `icv03-14`: လူအများရှေ့ပြောဆိုမှု — အများရှေ့ပြောရခြင်းနဲ့ လူမှုဆက်ဆံရေးတစ်ခုလုံး မတူကြောင်း။
- `icv03-18`: နှစ်ဖက်အတွက် နည်းလမ်းရှာခြင်း — မမျှတသောအခြေအနေတွင် အလျှော့ပေးရမည်ဟု မဆိုလိုကြောင်း။
- `icv03-25`: ပစ္စည်းနေရာတကျထားမှု — ပစ္စည်းထားရန် တည်ငြိမ်သောနေရာ ရှိ/မရှိ။
- `icv03-28`: အနုပညာလက်ရာ — အနုပညာစိတ်ဝင်စားမှုကို ဖန်တီးနိုင်စွမ်းနဲ့ မရောထွေးကြောင်း။
- `icv03-29`: မရင်းနှီးသောအတွေးကို ပယ်ချမှု — အန္တရာယ်ရှိသော/သတင်းမှားဖြစ်နိုင်သောအယူအဆကို သတိထားခြင်းနဲ့ မရောထွေးကြောင်း။

## ပါဝင်သူရွေးချယ်ခြင်း

အသက်၊ ပညာရေးနောက်ခံ၊ ဒေသ၊ နေ့စဉ်ဘာသာစကားအသုံးအနှုန်း မတူညီသူများကို ရွေးချယ်ပါ။ အစပိုင်း လူ ၆–၁၀ ယောက်သည် စကားလုံးနားလည်မှုဆိုင်ရာ အခက်အခဲတွေကို ဖော်ထုတ်ရန်သာ အသုံးဝင်သည်။ ထိုအရေအတွက်သည် Validation sample မဟုတ်ပါ။

## Privacy

အမည်၊ ဖုန်းနံပါတ် သို့မဟုတ် အခြားမလိုအပ်သော ကိုယ်ရေးအချက်အလက်များ မသိမ်းပါနှင့်။ ပါဝင်သူ၏ သဘောတူညီချက် ရယူပါ။ မှတ်တမ်းတင်မည်ဆိုပါက သီးခြားသဘောတူညီချက် ရယူပါ။
