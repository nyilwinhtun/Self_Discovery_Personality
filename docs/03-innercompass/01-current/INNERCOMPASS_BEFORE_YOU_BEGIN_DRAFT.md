# InnerCompass — Before You Begin (Draft)

## မစတင်မီ သိထားသင့်သော အချက်များ

### ဒီလေ့လာမှုရဲ့ ရည်ရွယ်ချက်

InnerCompass ဟာ နေ့စဉ်ဘဝမှာ ကိုယ်ဘယ်လိုစဉ်းစားတတ်သလဲ၊ ခံစားတတ်သလဲ၊ အခြားသူတွေနဲ့ ဘယ်လိုဆက်ဆံတတ်သလဲ၊ ဆုံးဖြတ်ချက်တွေကို ဘယ်လိုချတတ်သလဲဆိုတာ ပြန်လည်သုံးသပ်ဖို့ ရည်ရွယ်ထားတဲ့ ကိုယ်ပိုင်မေးခွန်းအစုတစ်ခု ဖြစ်ပါတယ်။ သင့်ကို အမျိုးအစားတစ်ခုတည်းနဲ့ အပြီးသတ်သတ်မှတ်ဖို့ မဟုတ်ပါဘူး။

### ဘယ်လိုဖြေဆိုသင့်သလဲ။

- ကိုယ်ဖြစ်ချင်တဲ့ပုံစံမဟုတ်ဘဲ နေ့စဉ်ဘဝမှာ အများအားဖြင့် ဖြစ်နေတတ်တဲ့ပုံစံကို အခြေခံပါ။
- မေးခွန်းတစ်ခုချင်းစီကို အလွန်အကျွံ မစဉ်းစားဘဲ ကိုယ့်အတွေ့အကြုံနဲ့ အနီးစပ်ဆုံး အဖြေကို ရွေးပါ။
- အဖြေမှန်၊ အဖြေမှား မရှိပါ။
- မသက်မသာဖြစ်စေတဲ့ မေးခွန်းကို ကျော်ထားနိုင်ပြီး ကိုယ်ရေးအတွေ့အကြုံကို ရှင်းပြဖို့ မလိုပါ။

### အဖြေရွေးချယ်မှု

1. လုံးဝ မကိုက်ညီပါ  
2. မကိုက်ညီပါ  
3. အလယ်အလတ်ပါ  
4. ကိုက်ညီပါသည်  
5. အလွန်ကိုက်ညီပါသည်

### ဖြေဆိုမှုကို စီမံနိုင်ပုံ

- မေးခွန်းတစ်ခုကို ကျော်ပြီး နောက်မှ ပြန်ဖြေနိုင်ပါတယ်။
- ယခင်မေးခွန်းတွေကို ပြန်ကြည့်ပြီး အဖြေပြင်နိုင်ပါတယ်။
- အချိန်မရွေး ခဏရပ်ပြီး နောက်မှ ဆက်ဖြေနိုင်ပါတယ်။
- အဖြေတွေကို ဒီ Browser နဲ့ ဒီစက်ထဲမှာ အလိုအလျောက် သိမ်းဆည်းမယ်။
- Browser Data ရှင်းမိရင် အချက်အလက်ပျောက်နိုင်တာကြောင့် JSON Backup ကို သိမ်းထားပါ။

### ရလဒ်ကို ဘယ်လိုနားလည်ရမလဲ။

ရလဒ်ဟာ ကိုယ်ဖြေဆိုထားတဲ့ အဖြေတွေကို အခြေခံတဲ့ ဖော်ပြချက်အညွှန်းသာ ဖြစ်ပါတယ်။ အမှတ်မြင့်ခြင်း၊ နိမ့်ခြင်းဟာ ကောင်းသူ၊ မကောင်းသူ သတ်မှတ်ချက် မဟုတ်ပါ။ အခြားသူတွေနဲ့ နှိုင်းယှဉ်ထားတဲ့ အဆင့်လည်း မဟုတ်ပါ။

### ဘာကို မဆုံးဖြတ်ပေးသလဲ။

ဒီလေ့လာမှုဟာ စိတ်ကျန်းမာရေးရောဂါ၊ ဉာဏ်ရည်၊ ကိုယ်ကျင့်တရားတန်ဖိုး၊ အနာဂတ်အပြုအမူ၊ အလုပ်အကိုင်အောင်မြင်မှုတို့ကို ရှာဖွေဖော်ထုတ်ပေးတာ မဟုတ်ပါ။ ဆေးဘက်ဆိုင်ရာ သို့မဟုတ် စိတ်ကျန်းမာရေး Diagnosis အတွက် မသုံးပါနှင့်။

### ကိုယ်ရေးအချက်အလက်

လက်ရှိအစီအစဉ်မှာ အဖြေတွေကို LocalStorage မှာပဲ သိမ်းဆည်းမယ်။ Cloud သို့ အလိုအလျောက် ပို့ခြင်း မရှိပါ။ Backup ဖိုင်ထဲမှာ ကိုယ်ရေးကိုယ်တာအဖြေတွေ ပါဝင်နိုင်တာကြောင့် လုံခြုံတဲ့နေရာမှာသာ သိမ်းပါ။
